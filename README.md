# Мои Отметки

Статическое веб-приложение для недельных, четвертных и годовых отметок. Сборка и внешние библиотеки не нужны. Проект подготовлен как устанавливаемое PWA с офлайн-кэшем.

## Структура проекта

Файлы должны лежать в корне публикуемого сайта:

```text
index.html
manifest.webmanifest
service-worker.js
netlify.toml
icons/
  app-192.png
  app-512.png
  app-maskable-512.png
  apple-touch-icon.png
  favicon-32.png
  app-icon.svg
```

Не публикуйте только `index.html`: без `manifest.webmanifest` и папки `icons/` браузер не сможет установить иконку, а без `service-worker.js` не будет офлайн-режима.

## GitHub и Netlify: пошаговая публикация

### 1. Загрузите проект в GitHub

1. Создайте новый GitHub-репозиторий (например, `moi-otmetki`).
2. Загрузите **содержимое проекта целиком**: в корне репозитория должны сразу отображаться `index.html`, `manifest.webmanifest`, `service-worker.js`, `netlify.toml` и папка `icons/`. Не загружайте файлы так, чтобы они оказались ещё на один уровень глубже, например `moi-otmetki/index.html` внутри корня репозитория.
3. Через сайт GitHub можно выбрать **Add file → Upload files**, перетащить файлы и папку `icons/`, затем нажать **Commit changes**. Если проект уже есть в локальном Git-репозитории, добавьте и отправьте изменения обычным `git add`, `git commit` и `git push`.
4. Откройте главную страницу репозитория и убедитесь, что список файлов показывает эту структуру в корне.

### 2. Подключите репозиторий к Netlify

1. В Netlify выберите **Add new site → Import an existing project → GitHub** и разрешите доступ к нужному репозиторию.
2. Выберите репозиторий и основную ветку (обычно `main`).
3. Для этого статического проекта **Build command оставьте пустой**, а **Publish directory укажите `.`**. `netlify.toml` в репозитории уже задаёт корень публикации и заголовки кэширования. Не задавайте отдельную Base directory, если файлы лежат в корне репозитория.
4. Нажмите **Deploy site**. После успешной публикации откройте выданный Netlify HTTPS-адрес. Последующие коммиты в подключённую ветку будут запускать новую публикацию автоматически.

### 3. Проверьте опубликованные файлы

Подставьте имя своего сайта и откройте по отдельности эти адреса. Каждый должен отвечать **200 OK**, а PNG-адреса должны показывать иконку:

   - `https://ВАШ-САЙТ.netlify.app/`
   - `https://ВАШ-САЙТ.netlify.app/manifest.webmanifest`
   - `https://ВАШ-САЙТ.netlify.app/service-worker.js`
   - `https://ВАШ-САЙТ.netlify.app/icons/app-192.png`
   - `https://ВАШ-САЙТ.netlify.app/icons/app-512.png`
   - `https://ВАШ-САЙТ.netlify.app/icons/app-maskable-512.png`
   - `https://ВАШ-САЙТ.netlify.app/icons/apple-touch-icon.png`

   Если хотя бы один адрес даёт 404, проверьте **Publish directory** и расположение файлов в репозитории. Папка `icons/` должна быть закоммичена в корень публикуемого проекта. Service Worker предварительно кэширует все эти ресурсы; если хотя бы одна иконка отсутствует, установка Service Worker может завершиться ошибкой и офлайн-кэш не заработает.

   Для `manifest.webmanifest` проверьте также заголовок `Content-Type: application/manifest+json`; его задаёт `netlify.toml`. Иконка в шапке актуального `index.html` встроена как SVG, но для экрана установки и iOS всё равно нужны PNG-файлы в `icons/`.

## Установка на устройство

- **Android / Chrome:** откройте опубликованный HTTPS-адрес и выберите «Установить приложение» (или пункт установки в меню браузера).
- **Компьютер / Chrome или Edge:** используйте значок установки в адресной строке или кнопку «Установить» в приложении, если браузер её показывает.
- **iPhone / iPad:** откройте сайт в Safari, нажмите **Поделиться → На экран Домой**. iOS использует `icons/apple-touch-icon.png`.
- Откройте приложение хотя бы один раз онлайн: после этого Service Worker сможет кэшировать оболочку для офлайн-запуска.

## Если иконка не обновилась

Иконка установленного PWA может кэшироваться браузером или операционной системой отдельно от сайта. После новой публикации:

1. Удалите старую иконку приложения с рабочего стола/экрана «Домой».
2. Очистите данные сайта и регистрацию Service Worker для домена (в Chrome: **Настройки сайта → Хранилище → Очистить**; на компьютере можно сделать это в DevTools → **Application → Storage → Clear site data**).
3. Полностью закройте вкладки сайта, откройте адрес заново и проверьте вкладку **Application → Manifest** в DevTools: там должны отображаться иконки 192×192 и 512×512.
4. Установите приложение заново.

Для обновления офлайн-кэша повышайте `CACHE_NAME` в `service-worker.js`. В текущей версии он обновлён до `my-marks-shell-v2`.

## Данные и отчёты

- Отметки и настройки хранятся локально в браузере на этом устройстве; синхронизации между устройствами нет.
- PDF недельного отчёта формируется локально. «Отправить отчёт» открывает системное меню «Поделиться», если браузер поддерживает передачу PDF; иначе файл скачивается для ручной отправки.
