# Мои Отметки

Локальное веб-приложение для недельных, четвертных и годовых отметок с расчётом средней оценки и денежной мотивацией.

## Запуск

Проект не требует сборки и внешних библиотек. Разместите все файлы проекта в одном каталоге и откройте через HTTPS. Для локальной разработки можно запустить:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. HTTPS (или `localhost`) нужен для установки PWA и работы Service Worker.

## Установка на устройство

- В поддерживаемых браузерах после загрузки появится кнопка **«Установить»**.
- На iPhone/iPad в Safari выберите **Поделиться → На экран Домой**.
- После первого открытия онлайн приложение кэширует оболочку и может запускаться офлайн.

## Данные и отчёты

- Отметки и настройки хранятся локально в браузере на этом устройстве; синхронизации между устройствами нет.
- PDF недельного отчёта формируется локально. Кнопка отправки открывает системное меню «Поделиться», если браузер поддерживает передачу PDF-файлов; иначе приложение скачает PDF для ручной отправки.

## Файлы PWA

- `manifest.webmanifest` — имя, режим запуска и иконки приложения.
- `service-worker.js` — кэш оболочки для офлайн-запуска.
- `icons/` — SVG-исходник, PNG-иконки для браузеров, установщиков и iOS.

При изменении ресурсов увеличьте версию `CACHE_NAME` в `service-worker.js`, чтобы установленное приложение обновило кэш.
